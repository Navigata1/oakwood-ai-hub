Do not build a computer lab. Build a production studio.

The strongest version of this proposal is not hardware-first. It is capability-first: students using AI, building AI systems, running local models, and governing AI responsibly.

Pillar 01

Use AI

Prompting, research, design, coding, analysis, presentations, and multimodal workflows with academic integrity rules.

Pillar 02

Build AI

Apps, agents, retrieval systems, dashboards, automations, voice, vision, and campus-facing prototypes.

Pillar 03

Run Local

Ollama, vLLM, quantization, GPU constraints, model serving, privacy, latency, and cloud-to-edge tradeoffs.

Pillar 04

Govern AI

Data classification, human approvals, audit trails, prompt injection tests, bias checks, and responsible deployment.

Four budget paths. One strategic ladder.

Each tier should be presented as a complete outcome path, not a raw shopping list. The choice depends on the funding window, procurement deadline, and desired institutional signal.

Starter Pod

$20K

Pilot path for fast proof of student interest.

  • 4-6 capable student seats
  • Shared local AI or edge AI node
  • Display, basic storage, open-source stack
  • Best for seed funding

Production Lab

$50K

Recommended minimum for a credible launch.

  • 6-10 strong seats
  • DGX Spark-class local node
  • Demo wall, NAS, managed network
  • 8-week pilot curriculum

Research Lab

$100K

Stronger institutional signal for faculty and grants.

  • Mixed premium seats
  • Local AI node plus GPU workstation
  • Studio and edge bench
  • Employer MOU and research framing

Flagship Center

$200K

Donor-ready center with visibility and naming potential.

  • 10 premium seats
  • Multiple local AI nodes
  • GPU server and full AV environment
  • External partner recruitment

Recommendation: lead with the $50K tier if the funding window is uncertain. Move to $100K if Dr. Smith has a real grant or donor lane. Save $200K for donor/naming or broader institutional capital.

90 days from commitment to demo day.

The plan moves quickly, but it respects the real blockers: procurement, IT, room readiness, lab ownership, and sustainment.

Weeks 1-2

Discovery and room plan

Confirm funding window, room, electrical/HVAC, network constraints, procurement path, and faculty/staff owner.

Weeks 3-6

Procurement and installation

Finalize SKUs, lock quotes, order hardware, configure storage/networking, and install the local model stack.

Weeks 7-10

Pilot cohort

Run students through app build, local model demo, governance/evaluation exercise, and presentation rehearsal.

Weeks 11-12

Demo day and next ask

Present student work to administrators, donors, and Huntsville employers; use outcomes to justify the next funding tier.
